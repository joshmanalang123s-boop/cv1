# Josh Manalang | Personal CV & Portfolio Website

A clean, minimalist, modern, and professional Personal CV and Portfolio website for **Josh Manalang**, an Information Technology student at **Angeles University Foundation** applying for internship opportunities.

---

## 🚀 How to Run the Website

### Option 1: Via XAMPP (Recommended)
1. Open the **XAMPP Control Panel** and ensure **Apache** is started.
2. Open your web browser and navigate to:
   ```text
   http://localhost/cv1/
   ```

### Option 2: Direct File Viewing
Double-click `index.html` to open and review it in any modern browser (Chrome, Edge, Firefox, Brave, Safari).

## 🔍 Interactive High-Resolution Lightbox
Clicking any project screenshot or the **"View Full Screenshot"** button instantly opens a full-screen, high-resolution modal with caption support so recruiters can clearly inspect your interface, tables, and workflows without any cropping.

## 📄 How to Attach Your Resume PDF
1. Name your finalized resume PDF: `resume.pdf`
2. Place it in: `assets/docs/resume.pdf`
3. All "Download CV" buttons across the navbar, hero section, and resume section will automatically download it as `Josh_Manalang_CV.pdf`.
